# Tailscale PC Admin + Windows Auto-Start

This is the optional self-hosted PC companion for LR's Sangeet_Duniya. User data and token records stay on the PC filesystem; Tailscale supplies the network path.

## PC server

From the repository folder:

    python tools/tailscale_admin_server.py

The server listens on 127.0.0.1:40426 and creates \`.lrs-admin-data/config.json\`, \`tokens.json\`, and \`users.json\`.

## Check existing Tailscale settings without changing them

    tailscale status
    tailscale serve status
    tailscale funnel status

Do not use \`tailscale serve reset\` or \`tailscale funnel reset\`; those clear existing configuration.

## Windows automatic startup + self-check

The repository includes:

    tools/windows_lrs_server_watchdog.ps1

Run **PowerShell as Administrator** in the repository folder and install it:

    Set-ExecutionPolicy -Scope Process Bypass
    .\tools\windows_lrs_server_watchdog.ps1 -Mode Install

The task is named:

    LRs Sangeet_Duniya PC Admin Watchdog

It starts at Windows startup with a 30-second random delay and checks the local PC admin server every 20 seconds. If \`/health\` stops responding, it restarts **only** the LRS Python server process. Every five minutes it also checks the Tailscale Windows service, \`tailscale status\`, \`tailscale serve status\`, and \`tailscale funnel status\`.

The watchdog does **not** run \`tailscale serve reset\`, \`tailscale funnel reset\`, or rewrite existing Serve/Funnel configuration.

### One-shot checker

    .\tools\windows_lrs_server_watchdog.ps1 -Mode Check

This prints:

- LRS PC server health
- matching server process/PID
- Tailscale Windows service state
- Tailscale status
- Serve status
- Funnel status
- log file locations

### Logs

    C:\ProgramData\LRS-Sangeet-Duniya\watchdog.log
    C:\ProgramData\LRS-Sangeet-Duniya\server.stdout.log
    C:\ProgramData\LRS-Sangeet-Duniya\server.stderr.log

### Disable or remove auto-start

    .\tools\windows_lrs_server_watchdog.ps1 -Mode Uninstall

This removes only the Windows scheduled task. It does not modify Tailscale Serve or Funnel.

### Optional Tailscale service repair

By default, the watchdog does not change the Tailscale service if it is stopped. To explicitly allow it to start the Windows Tailscale service when it detects it stopped, install with:

    .\tools\windows_lrs_server_watchdog.ps1 -Mode Install -RepairTailscaleService

This still does not reset or rewrite Serve/Funnel configuration.

## Tailscale

Because your PC already runs another Tailscale project, keep its current configuration intact.

Private Serve example:

    tailscale serve --https=8443 http://127.0.0.1:40426

Public Funnel example:

    tailscale funnel --https=8443 http://127.0.0.1:40426

Choose a port not already used by your existing project.

Use the USER KEY in the app user's activation link:

    https://YOUR-PC-TS-NAME:8443/?key=USER_KEY

Use the ADMIN KEY only in the admin phone:

    https://YOUR-PC-TS-NAME:8443/?key=ADMIN_KEY

On the admin phone, open Sangeet_Duniya -> Admin Dashboard -> Tailscale PC admin, paste the ADMIN URL, Save, then Sync PC.

New tokens generated by the owner phone are synchronized to the PC. Users can then register against the USER URL.
