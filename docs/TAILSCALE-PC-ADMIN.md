# Tailscale PC Admin

This is an optional self-hosted PC companion for LR's Sangeet_Duniya. User data and token records stay on the PC filesystem; Tailscale supplies the private network path.

## PC

Run from the repository folder:

    python tools/tailscale_admin_server.py

The server listens on 127.0.0.1:40426 and creates .lrs-admin-data/config.json, tokens.json, and users.json.

## Tailscale

Because your PC already runs another Tailscale project, check the current configuration before adding anything:

    tailscale serve status
    tailscale funnel status

Do not use `tailscale serve reset` or `tailscale funnel reset`; those clear existing configuration. Tailscale Serve is private to the tailnet, while Funnel publishes the selected service to the public Internet over HTTPS. 

Private Serve example:

    tailscale serve --https=8443 http://127.0.0.1:40426

Public Funnel example:

    tailscale funnel --https=8443 http://127.0.0.1:40426

Choose a port not already used by your existing project. Tailscale currently permits HTTPS on 443, 8443, and 10000 for Funnel.

## Two links

Use the USER KEY in the app user's activation link:

    https://YOUR-PC-TS-NAME:8443/?key=USER_KEY

Use the ADMIN KEY only in the admin phone:

    https://YOUR-PC-TS-NAME:8443/?key=ADMIN_KEY

On the admin phone, open Sangeet_Duniya -> Admin Dashboard -> Tailscale PC admin, paste the ADMIN URL, Save, then Sync PC.

New tokens generated by the owner phone are synchronized to the PC. Users can then register against the USER URL.

## Important

The PC must be powered on, the Python server must be running, and the selected Tailscale Serve/Funnel configuration must be active for remote registration. This is not an always-on hosted cloud server.

Tailscale's current Personal plan is free and allows up to 6 Tailscale users with unlimited devices. That is a Tailscale account limit, not a limit on the number of app-user records stored in the PC JSON database.
